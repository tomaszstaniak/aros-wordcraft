Other material built into WordCraft and wordcraft-cli for AROS
==============================================================

Target: AROS x86_64, mainline ABIv1.

Both programs are statically linked. Nothing below has to be installed
separately; the programs use only libraries that are part of AROS itself.

AROS link libraries
  The startup code, library stubs and the POSIX threads library
  (libpthread) come from the mainline AROS SDK of the nightly build of
  2026-11-05, unchanged, and are covered by the AROS Public License,
  version 1.1 (AROS-LICENSE.txt, https://aros.sourceforge.io/license.html).

GCC runtime library
  libgcc from GCC 10.5, under the GNU General Public License version 3
  with the GCC Runtime Library Exception.

Rust standard library
  The Rust standard library and its dependencies, under the MIT license or
  the Apache License 2.0 (see THIRD-PARTY.txt and the Rust drawer).

C library bindings and entropy source
  rust-aros libc-aros (MIT license, Copyright (c) 2026 Tomasz Staniak),
  which includes jitterentropy-library 3.7.0 (BSD-3-Clause) and an adapter
  from arospkg (MIT license). Their license texts follow in THIRD-PARTY.txt.
